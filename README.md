# scoopcsv

Scoop encode/decode helpers for csv payloads in pipelines.

**Site:** https://theworker02.github.io/scoopcsv/

## Install / run

```bash
git clone https://github.com/theworker02/scoopcsv.git
cd scoopcsv
node src/cli.js
node --test
```
